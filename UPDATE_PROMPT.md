# K World Replayability Update Prompt

Update the existing K World educational RPG without replacing its current visual identity, age adaptation, local saving, accessible narration, playable overworld, or GitHub Pages deployment.

## Player controls

- Add a clearly labeled way to restart the current quest from its first activity without losing the child’s overall stars, XP, facts, badges, or settings.
- Add a “Change hero” option from the main game navigation and settings so the child can return to character selection at any time. Preserve progress while allowing the avatar, outfit, class, nickname, and companion to be changed.
- After a quest is completed, offer both “Try a new quest here” and “Return to world map.”
- Make restart actions friendly and unambiguous. Never erase overall progress unless the grown-up explicitly uses the existing full-reset control.

## More quests and activities

- Give every region at least four distinct story-based quest variants with different names, introductions, activity themes, and learning purposes.
- Expand the age-appropriate question and activity pools for science, mathematics, and English. Include a balanced mixture of habitats, plants, space, the body, experiments, arithmetic, patterns, fractions, geometry, logic, spelling, grammar, vocabulary, comprehension, and storytelling.
- Puzzle Peaks and Inventor’s Island must draw from mixed-subject pools and use their own original quest stories.
- Keep facts and answers accurate, feedback constructive, and difficulty suitable for Ages 5–7, Ages 8–10, and Ages 11–13.

## Randomization without immediate repetition

- Select a random quest variant whenever the player enters a region.
- Select a fresh set of activities from that region’s age-appropriate pool.
- Track recently used quest variants and questions locally for each region.
- Do not repeat a quest variant until the other variants in that region have been used.
- Do not repeat questions from the immediately previous quest. Cycle through the available pool before recycling older activities.
- Ensure activities within one quest are unique.
- Save rotation history locally without requiring an account or collecting personal data.

## Experience and accessibility

- Show the selected quest’s title, activity type, and short story introduction before play begins.
- Keep read-aloud controls available for quest introductions, questions, answers, hints, and feedback.
- Make all new buttons accessible by keyboard, mouse, and touch.
- Preserve the forgiving, no-lives, no-shame approach and the existing static GitHub Pages compatibility.

Implement the complete working update, including navigation, state logic, random selection, no-repeat rotation, local persistence, responsive styling, and production validation. Do not create only a mockup.
